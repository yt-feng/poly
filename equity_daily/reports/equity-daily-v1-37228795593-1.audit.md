# `equity-daily-v1-37228795593-1` independent bundle audit

This is an offline content audit of three downloaded release bundles. Release
metadata and the complete asset inventory are recorded in
[`equity-daily-v1-37228795593-1.metadata.json`](equity-daily-v1-37228795593-1.metadata.json);
the machine-readable observations are in
[`equity-daily-v1-37228795593-1.audit.json`](equity-daily-v1-37228795593-1.audit.json).
The release itself was not changed.

## Reproduce

Download only the first, middle and last tar plus their `.sha256` sidecars into
one temporary directory, then run:

```bash
python -m equity_daily.release_audit \
  --input-dir /tmp/equity-release-audit-37228795593-1 \
  --metadata equity_daily/reports/equity-daily-v1-37228795593-1.metadata.json \
  --output /tmp/equity-daily-v1-37228795593-1.audit.json
```

The command is read-only with respect to the inputs. It rejects path-traversal
members, verifies outer and inner SHA256 sidecars and every retained payload
SHA256, and removes its temporary extraction directory. It does not fetch data,
decrypt an archive, or infer missing observations.

## Known limits

All selected manifests say `live_trading_enabled=false`, `strategy_evaluated=false`
and `continuity_guaranteed=false`. Alpaca is unconfigured in every sample, so
no entitled exchange trade/quote evidence is present. In bundle 000025 the
futures symbols `CL=F`, `GC=F`, `NG=F`, and `SI=F` are explicitly
`metadata_only_no_bars` (the index `DX-Y.NYB` has the same state); bundle 000049
later reports chart bars for those symbols, which does not retroactively fill
the earlier gap. No sample establishes official settlement or executable fills.

This audit is evidence about archive integrity and observed payload shape only;
it is not canary evidence, profitability evidence, or proof that a public quote
could have been executed at the recorded price.
